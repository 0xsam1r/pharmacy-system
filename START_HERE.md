## 🚀 How to Run

### Method 1 - NetBeans (Recommended):
```
1. Open project in NetBeans
2. Set Main Class: gui.PharmacyApp
3. Set VM Options: 
   --module-path "path/to/javafx/lib" 
   --add-modules javafx.controls,javafx.fxml
4. Press F6
```

### Method 2 - Batch File:
```
1. Edit run_gui.bat
2. Set JavaFX path
3. Double-click the file
```
